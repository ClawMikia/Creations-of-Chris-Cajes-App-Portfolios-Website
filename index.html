💡 Dynamic Folder Auto-Sync

Want to add more HTML pages/apps?

Simply create a new subfolder in web_version/ (e.g., web_version/app5/index.html). The dynamic engine automatically discovers new folders and renders their cards!

📁 Adding New HTML Folders

To add a new project to this web portal:

  1. Create a new folder inside web_version/ (e.g. app5/).
  2. Place an index.html inside your new folder.
  3. (Optional) Include <meta name="description">, <meta name="app-icon">, and <meta name="app-tags"> in the HTML header for custom card details!
  4. Click Scan New Folders or refresh the home page!
