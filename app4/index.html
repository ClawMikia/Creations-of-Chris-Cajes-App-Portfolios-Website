Section 01

Introduction

La-Fierce Admin is a Windows Forms CRUD tool targeting success stories via the API. It provides authenticated administration, responsive dark theme, data table list with badges, and rich detail view with content highlighting.

Interfaces are built with custom theming in mind using ThemeManager, and the UI uses a card layout, accent actions, and custom owner-drawn list states.

✨

Dark UI

Primary design uses #161616 background with #ff3700 accent and clean readable typography.

🛠️

Operations

Create, Read, Update, Delete, toggle status and filter/search records in one panel.

🌐

API integration

REST API calls from HttpClient for list, detail, edit, delete, status patch with error handling.

🖥️

Responsive layout

Adaptive panels, side content, draggable views, and dark title bar plugin on Windows.

🛠️

Section 04

Main Dashboard

The dashboard has header, left list panel, right detail panel, and bottom status bar. Use search and sort on the left to filter people, and action buttons to modify data.

🔍

Search

Text search across person names (case-insensitive).

↕️

Sort

Name and status sort options.

✔️

Buttons

Refresh, Add, Edit, Delete, Toggle status.

👥
Section 05

People List

PersonListBox is owner-drawn with two-line row, status dot, selection accent, and alternating row colors. Active = green dot; Inactive = yellow dot. Selected entry is red-accented.

💡

Empty portion below list is repainted to avoid white background gap in dark theme.

📖
Section 06

Detail View

Select a person to load detail via /api/successstories/{id}. Shows HEADline + active/inactive badge and story text sections with highlight phrase coloring.

✎
Section 07

Editor Dialog

In the editor form, enter name, status, rejection and success story, and manage highlight phrases. Selected text from story boxes can be copied into highlight phrase with section assignment.

1
Add highlighter Select text in story, click + Add.
2
Save Click Save to close dialog and call POST/PUT API.
🌙
Section 08

Theme Toggle

Toggle by header button. ThemeManager toggles colors on all controls. Light mode uses variant palettes, dark mode uses base dark palette (#161616). The selected mode persists in the running session only.

🌐
Section 09

API Endpoints

Endpoints used in code:

HTTPPathDescription
GET/api/successstoriesLoad all records
GET/api/successstories/{id}Load detail with highlights
POST/api/successstoriesCreate record
PUT/api/successstories/{id}Update record
DELETE/api/successstories/{id}Delete record
PATCH/api/successstories/{id}/statusToggle active/inactive
📌

HttpClient uses permissive certificate validation and 60s timeout; adjust for production with proper certificate handling.

Section 10

FAQ

Q: What are credentials?

Valid credentials are hard-coded in LoginForm.

Q: How to handle backend errors?

Errors are surfaced in status bar and exception message. Use API retry or inspect server connection.

Q: Visual snapping issue?

Appearance may flicker on resize; it is manually mitigated in panel Resize and Load event hack in code.
